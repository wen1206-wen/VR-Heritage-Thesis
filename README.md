# VR Heritage Access Prototype

This repository contains the prototype developed for my REIT7842 thesis project.

## Project Title

VR-Based Remote Access and Condition Visualisation for Temporarily Closed Cultural Heritage Sites

## Project Overview

This project investigates how a lightweight virtual reality experience can provide alternative public access to cultural heritage environments when physical access is temporarily restricted due to conservation requirements, maintenance, floods, cyclones, or other environmental risks.

The prototype will allow users to explore a virtual heritage environment and interact with deterioration hotspots that communicate visible conditions such as cracking, weathering, surface loss, discolouration, and water staining.

## Research Question

How can a lightweight VR experience provide public access to a temporarily closed cultural heritage site while communicating visible deterioration and reducing the need for direct physical access?

## Prototype Scope

The initial prototype will include:

- One small cultural heritage environment
- VR navigation
- Three to five deterioration hotspots
- Interactive condition information panels
- A simulated temporary closure scenario

## Tools

- Unity LTS
- OpenXR
- XR Interaction Toolkit

- Meta Quest or available university VR headset
